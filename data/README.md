# Data

1. Go to https://www.kaggle.com/competitions/walmart-recruiting-store-sales-forecasting/data (free Kaggle account).
2. Click **Late Submission** or **Join Competition** once to accept the rules. Kaggle requires this before downloading competition data.
3. Download all files, unzip them, and put these three in this folder:

```
train.csv
features.csv
stores.csv
```
